You are viewing slipt-rho.vercel.app. This multi-portal UPI Gateway and Terminal Management system requires persistent state, local Wi-Fi pairing, and real-time WebSockets, which are intended for local execution.

🔄 Stateful WebSockets

Instantaneous bi-directional updates between merchant dashboards and paired customer terminals with room isolation.

📶 Local Wi-Fi Phone Testing

Pairs mobile phones over the same local router network via local IP (e.g. 192.168.1.7:3000).

🛡️ Terminal 3 Enforcement

Enforces strict 2-terminal concurrent limits per merchant code with instant 403 blocking on Terminal 3.

⚡ ≤ ₹1999 Auto-Splitting

Automated payment chunk calculation and round-robin destination UPI routing across multiple accounts.

🚀 Quick Setup: Run Locally in 3 Commands
1. Clone Repository:
git clone https://github.com/shubhG-9401/SLIPTE-PAYMENT.git
2. Install Dependencies:
cd SLIPTE-PAYMENT && npm install
3. Launch Local Server:
npm start
